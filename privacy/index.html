ARTRAS / PRIVACY

개인정보처리방침

시행일 2026년 10월 19일 · 운영자 김준학

작품은 아이폰 안에서 처리합니다. 고객지원 이메일과 웹사이트 호스팅의 정보 처리도 함께 안내합니다.

1. 적용 범위

이 방침은 김준학이 운영하는 Artras 앱, 이 웹사이트 및 이메일 고객지원에 적용됩니다. Artras는 평평한 작품을 여러 장의 사진으로 촬영하고 아이폰에서 합성하는 앱입니다.

2. 사진과 작품 정보

촬영 사진, AR 촬영 위치·각도, 작품 범위, 합성 결과 및 사용자가 입력한 작품 정보는 기기 내 앱 보관함에 저장되며 합성과 작품 관리에 사용됩니다. 앱은 이 정보를 개발자 서버로 자동 업로드하지 않습니다. 회원가입, 광고, 광고 목적의 추적 및 별도 이용 분석 SDK는 없습니다.

3. 접근 권한

  • 카메라: 작품 촬영과 AR 추적에 사용합니다.
  • 위치: 선택 사항입니다. 허용하면 첫 사진의 촬영 위치를 메타정보에 기록합니다. 거부해도 촬영·합성이 가능합니다.
  • 사진 보관함 추가: 결과 이미지를 사진 앱에 저장할 때 사용합니다.

아이폰 설정에서 권한을 변경할 수 있습니다. 위치 권한을 철회해도 이미 저장하거나 내보낸 이미지의 위치 정보는 자동으로 제거되지 않습니다.

4. 내보내기와 백업

사용자가 사진·파일 앱이나 공유 대상을 선택하면 결과가 해당 저장 위치 또는 서비스로 전달됩니다. 이미지에는 촬영 날짜·위치, 작품명·작가·메모 등의 메타정보가 포함될 수 있습니다. 공유 전 포함된 정보를 확인해 주세요.

기기 백업, iCloud 사진 및 사용자가 선택한 서비스에는 해당 서비스의 설정과 정책이 적용됩니다. Artras 자체의 클라우드 동기화 기능은 없습니다.

5. 보관과 삭제

앱 보관함의 촬영본과 결과는 사용자가 삭제할 때까지 저장됩니다. 보관함에서 삭제하면 해당 항목의 앱 내부 원본과 결과가 삭제됩니다. 내보낸 사본과 기기 백업은 별도로 관리해야 합니다. 앱 삭제 시 로컬 데이터가 제거될 수 있으므로 필요한 자료를 먼저 보관해 주세요.

6. 고객지원 이메일

문의에 포함된 회신 이메일 주소, 이름(제공한 경우), 문의 내용 및 첨부자료를 문의 대응에 사용합니다. 작품 원본이나 민감한 자료를 첨부할 필요는 없습니다. 문의 정보는 문의 해결 후 1년간 보관한 뒤 삭제합니다. 더 이른 삭제나 열람·정정 요청은 incago@gmail.com로 보내실 수 있습니다. 기기에만 있는 사진은 운영자가 원격으로 열람·삭제할 수 없으므로 앱에서 직접 관리해 주세요.

이메일 전달과 보관에는 Gmail을 사용하며 이메일 서비스의 처리에는 Google Privacy Policy도 적용됩니다.

7. 웹사이트 호스팅

이 사이트는 GitHub Pages에서 제공됩니다. GitHub는 사이트 방문자의 IP 주소를 보안 목적으로 기록·보관합니다. 자세한 내용은 GitHub Privacy Statement에서 확인할 수 있습니다. 운영자는 이 사이트에 별도 광고, 방문 분석 도구, 추적 쿠키 또는 문의 양식을 설치하지 않았습니다.

8. 정책 변경 및 문의

데이터 처리 방식이 바뀌면 이 페이지와 시행일을 갱신합니다. 개인정보 관련 문의와 요청은 운영자 김준학에게 incago@gmail.com로 보내주세요.
